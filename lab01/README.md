# ColorLab — лабораторная работа №1 (вариант 5)

Приложение для интерактивной работы с цветом в трёх моделях:
**CMYK ↔ LAB ↔ HSV**.

## Возможности

- Задание цвета **тремя способами**:
  1. Поля ввода (у каждой компоненты).
  2. Ползунки с цветными градиентами.
  3. Палитра (`colorchooser`) и HEX-поле.
- **Автоматический пересчёт** всех трёх моделей при изменении любой компоненты.
- **Предупреждение о clipping** — когда при преобразовании (например, LAB → RGB)
  значение выходит за границы sRGB-гамута и обрезается.
- Сохранение и загрузка цвета в текстовый файл.

## Схема преобразований

| Из   | В    | Путь                    |
|------|------|-------------------------|
| CMYK | LAB  | CMYK → RGB → XYZ → LAB  |
| LAB  | CMYK | LAB → XYZ → RGB → CMYK  |
| CMYK | HSV  | CMYK → RGB → HSV        |
| HSV  | CMYK | HSV → RGB → CMYK        |
| LAB  | HSV  | LAB → XYZ → RGB → HSV   |
| HSV  | LAB  | HSV → RGB → XYZ → LAB   |

## Математика

- **RGB ↔ CMYK**: `K = min(1−R/255, 1−G/255, 1−B/255)`; `C = (1−R/255−K)/(1−K)` и т.д.
- **RGB ↔ HSV**: стандартное преобразование; H в [0,360), S,V в [0,1].
- **RGB ↔ XYZ** (D65): гамма-коррекция sRGB и матрица перехода
  `[0.412453 0.357580 0.180423; 0.212671 0.715160 0.072169; 0.019334 0.119193 0.950227]`,
  нормировка на 100.
- **XYZ ↔ LAB** (D65: Xw=95.047, Yw=100, Zw=108.883): функция `F(x) = x^(1/3)`
  при `x ≥ 0.008856`, иначе `7.787·x + 16/116`.
- **Out of Gamut**: если LAB→RGB даёт значения вне [0,255], применяется Clipping
  через `max(0, min(255, C))` и выводится предупреждение.

## Запуск

Требуется **Python 3.10+**. Tkinter входит в стандартную поставку.

```
python colorlab.py
```

## Сборка .exe

```
pip install pyinstaller
pyinstaller --onefile --windowed --name ColorLab colorlab.py
```

Готовый `ColorLab.exe` появится в папке `dist/`.
